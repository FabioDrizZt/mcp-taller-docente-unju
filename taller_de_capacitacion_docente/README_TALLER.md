# Taller de Capacitación Docente: Agentes MCP y ClassMoji

**Duración:** 2 Jornadas (10 horas totales entre teoría sincrónica y práctica asincrónica)
**Objetivo:** Empoderar al cuerpo docente de la UCSE-DASS en la creación de ecosistemas de evaluación continua autoguiada y resiliencia pedagógica utilizando IA generativa (Protocolo MCP) y Git (ClassMoji).

---

## Estructura del Taller (Enfoque Práctico-Vivencial)

La propuesta pedagógica de este taller es de inmersión ("vivir la experiencia del alumno para diseñar como docente"). Por ello, el taller se divide estratégicamente en dos jornadas:

### [Día 1: Fundamentos, Ética y Onboarding](dia_1_fundamentos_y_setup/)
El objetivo del primer día es nivelar el conocimiento técnico y pedagógico, y hacer que los docentes vivan la experiencia desde el rol del estudiante.

* **Teoría (Conceptos Clave):**
  - **Ecosistema de IA:** Qué es el contexto, cómo operan los agentes y el Protocolo MCP (vs chatbots tradicionales).
  - **Ingeniería Didáctica con IA:** Prompt Engineering aplicado a la docencia, ecosistema de *Skills* y la metodología SDD (Spec-Driven Development) para prevenir alucinaciones.
  - **Dimensión Ética y Pedagógica:** Mitigación de sesgos, autoaprendizaje, autorregulación metacognitiva y el rol irremplazable del docente.
* **Laboratorio Práctico (Onboarding):** 
  - Creación de cuentas de GitHub.
  - Aceptación de invitación a la organización de ClassMoji del taller.
  - **Actividad Autoevaluativa:** Realización de un pequeño cuestionario/desafío interactivo sobre los temas del Día 1, el cual les brindará retroalimentación automática usando las mismas herramientas que luego usarán con sus alumnos.

### [Día 2: Flujo Operativo y Creación de Actividades](dia_2_flujo_practico/)
Con las cuentas configuradas y las invitaciones aceptadas, el segundo día se centra en el rol docente ("backstage").

* **Teoría (Flujo de Trabajo ClassMoji):**
  - Entendiendo ClassMoji: Manejo de economía de tokens (Puntos de Ritmo) y evaluación cualitativa con emojis.
  - Creación de un "Assignment" (Tarea).
  - Cómo enganchar un *Skill* SDD para autoevaluar entregas.
* **Laboratorio Práctico (El Docente Creador):**
  - Cada docente clonará una plantilla base y configurará su primera tarea automatizada para su materia específica.
  - Pruebas de fuego: Simulando una entrega de un alumno para ver cómo actúa el agente.
