# Conclusiones Preliminares (Hito Semestral: Avance 50%)

## 1. Síntesis de Logros Alcanzados
Al cumplirse la primera mitad del cronograma de investigación (Noviembre 2025 – Junio 2026), se extraen las siguientes conclusiones preliminares:

1. **Viabilidad Técnica de MCP en Educación Informática:**
   El Model Context Protocol demostró ser una solución arquitectónica sólida, desacoplada y eficiente para conectar clientes de inteligencia artificial con herramientas deterministas de inspección de código (DOM, CSS, compiladores y runners de pruebas).
2. **Efectividad del Autograding en la Autorregulación:**
   La integración de GitHub Actions combinada con el "Sistema de Puntos de Ritmo" impactó positivamente en la conducta de los estudiantes de *Programación II*, induciendo un hábito de trabajo continuo e iterativo y desterrando la entrega tardía de código no verificado.
3. **Resiliencia Operativa y Capacidad de Pivoteo:**
   Frente a contingencias no previstas (límites de minutos en GitHub Actions y desorientación inicial de alumnos recursantes), el enfoque de investigación-acción permitió implementar soluciones oportunas y definitivas (adopción de repositorios públicos para entregas formativas y automatización con `setup-issues.yml`), convirtiendo obstáculos técnicos en aprendizajes metodológicos de alto valor.
4. **Soberanía Tecnológica frente a la Obsolescencia de Plataformas:**
   El cierre definitivo de GitHub Classroom en agosto de 2026 validó empíricamente la premisa fundacional del proyecto: la adopción de estándares abiertos (Model Context Protocol, Git nativo, GitHub Actions desacoplados y andamiaje universal) inmuniza a las cátedras contra el *vendor lock-in*. La transición fluida hacia **ClassMoji** (Traore & Tregubov, 2026) no solo preservó el 100% de los evaluadores y flujos construidos, sino que potenció la evaluación formativa mediante emojis y flexibilizó los plazos con su economía de tokens sincronizada con los Puntos de Ritmo.
